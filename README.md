# Project TENKA (天下)

**4大英雄自律エージェント × 独自RAGによる未踏領域マネタイズ基盤**

織田信長・豊臣秀吉・徳川家康・聖徳太子の4大英雄ペルソナを持つ自律型マルチエージェントと、ローカルハイブリッドRAGエンジンを統合した実験プロジェクト。

## 🌐 作戦司令室ダッシュボード
- GitHub Pages: https://maoum-cmd.github.io/project-tenka/

## 🏛️ 四英雄エージェント構成
- **⚔️ 織田信長 (Disruption Engine)**: 既存の独占関所（高額中抜き）を破壊する逆張りフリーミアム戦略
- **🌾 豊臣秀吉 (Data Harvester)**: 未構造化データ（地方自治体入札・公募PDF）の太閤検地
- **🛡️ 徳川家康 (Governance & Cashflow)**: 著作権法30条の4準拠とエージェント間取引（A2A）による永続年貢システム
- **📜 聖徳太子 (Synthesis & Innovation)**: 十人調停による異分野知財結合と未踏ビジネス創出

## 📂 ディレクトリ構成
- `agents/`: 各英雄エージェントの実装
- `core/`: ハイブリッドRAGエンジンおよび天下統一評定エンジン
- `data/`: 検地用データセット
- `output/`: 軍議レポートおよびダッシュボードHTML
